# atom_os — 差分方程式の導出

`src/atom_os.cpp` の 3 階層それぞれについて、更新式を導出して書き下したもの。
コードはこの式をそのまま書いただけで、それ以外のことはしていない。

- レベル 1: 原子・分子の電子 → 変分モンテカルロ (VMC)
- レベル 2: 原子核の陽子・中性子 → 量子分子動力学 (QMD)
- レベル 3: 核子の中のクォーク → 相対論的コーネル型 + Y ストリング

---

## 0. なぜ電子だけ「モンテカルロ」なのか

点電子をクーロン力で古典的に回すと、s / p 軌道は**原理的に出ない**。

- 古典電子は加速運動で電磁波を放射して核に落ちる（古典原子は安定でない）
- 殻構造・パウリ排他・p 軌道のローブは、多体波動関数の**反対称性**から出る性質で、
  1 体の軌道方程式には入っていない

「粒子としてシミュレーションして、しかも正しい軌道を出す」正しい方法は、
点粒子（ウォーカー）に多体確率密度 |Ψ(r₁…r_N)|² をサンプリングさせること。
これは量子化学が実際に使っている手法（VMC / DMC）で、近似は試行関数 Ψ_T の形だけ。
サンプリング自体は厳密。

## 1. 電子：メトロポリス・ドリフト拡散差分方程式

### 1.1 試行関数

原子単位 (ħ = m_e = e = 1)。

```
Psi_T(R) = det[ Phi_j(r_i) ]_up * det[ Phi_j(r_i) ]_dn * exp(J)

Phi_j  = sum_k c_jk chi_k                    LCAO 分子軌道
chi    = 水素型スレーター軌道（中心 A、指数 zeta）
J      = sum_{i<j} a_ij u(r_ij),   u(r) = r / (1 + b r)
a_ij   = 1/2  (反平行スピン)
         1/4  (平行スピン)
```

`a_ij` は勝手な値ではなく**電子‑電子カスプ条件**そのもの。
`b` と `zeta` のスケール、および分子の結合分極 `lambda` は変分最適化する
（目的関数はモデル自身の ⟨E_L⟩ で、実験値は一切使わない）。

原子軌道の動径部分（λ = ζ/n）:

| n, l | 形 |
|---|---|
| 1s | `exp(-λr)` |
| 2s | `(1 - λr) exp(-λr)` |
| 2p | `x_m exp(-λr)` |
| 3s | `(1 - 2λr + (2/3)λ²r²) exp(-λr)` |
| 3p | `x_m (1 - λr/2) exp(-λr)` |

これは水素原子の厳密な動径関数なので、節の構造が正しい。
ラプラシアンも解析的に出る（s 型 `g(r)` は `g'' + 2g'/r`、
p 型 `x h(r)` は `x (h'' + 4h'/r)`）。

### 1.2 サンプリング（ここが差分方程式）

f(R) = |Ψ_T(R)|² を定常解に持つフォッカー・プランク方程式を書く。

```
df/dt = D grad . ( grad f - F f ),     F = grad ln|Psi_T|^2 = 2 grad Psi / Psi
```

対応するランジュバン方程式を伊藤離散化する（1 電子ずつ動かす）。D = 1/2。

```
r_i^{n+1} = r_i^n + D tau_i F_i(R^n) + sqrt(2 D tau_i) xi ,   xi ~ N(0,1)^3
```

τ が有限だとこれは分布にバイアスを持つ。そこで提案密度

```
G(r->r') = (4 pi D tau)^{-3/2} exp( -|r' - r - D tau F(r)|^2 / (4 D tau) )
```

に対するメトロポリス・ヘイスティングス採択

```
A = min( 1,  |Psi(R')|^2 G(r'->r) / ( |Psi(R)|^2 G(r->r') ) )
```

を掛ける。これで**任意の τ について分布が厳密に |Ψ_T|²**（時間刻み誤差ゼロ）。

τ は位置依存にしてある（核の近くで小さく、価電子領域で大きく）:

```
tau(r) = tau0 * d^2 / (a^2 + d^2) ,   d = 最近接核までの距離, a = 1/Z
```

位置依存でも、逆向き遷移で τ(r′) を使えば MH は厳密なまま。
そのため両方向の規格化因子 (2πs²)^{-3/2} を省略していない
（s0 ≠ s1 なので、ここを落とすと分布が歪む）。
ドリフトの大きさには上限 2·s0 を掛けているが、これも位置の決定的関数なので厳密性は保たれる。

### 1.3 1 電子移動の Ψ 比（O(N)）

A_ij = Φ_j(r_i)、Ainv = A⁻¹ とすると

```
ratio_det           = sum_j Phi_j(r_i') * Ainv[j][i]
grad ln det |_{r_i'} = ( sum_j Ainv[j][i] grad Phi_j(r_i') ) / ratio_det
```

採択されたら A の第 i 行を差し替えて逆行列を更新する。

### 1.4 局所エネルギー（正しさの検証量）

```
E_L(R) = -1/2 sum_i (lap Psi/Psi)_i + V(R)

(lap Psi/Psi)_i = (lap det/det)_i + lap_i J + |grad_i J|^2
                  + 2 (grad_i ln det) . (grad_i J)
(lap det/det)_i = sum_j Ainv[j][i] lap Phi_j(r_i)

V = -sum_A Z_A/|r_i - R_A| + sum_{i<j} 1/r_ij + sum_{A<B} Z_A Z_B/R_AB
```

⟨E_L⟩ は変分エネルギー = 真の基底状態の**上限**。
誤差はブロック平均法で出す（連続サンプルは相関するので √(var/N) は過小評価になる）。

### 1.5 分子軌道

行列式には 1 電子軌道が必要で、分子では LCAO でなければ**化学結合が出ない**
（裸の原子軌道の行列式は「隣に置いただけの原子 2 個」で、核間反発の分だけ
分離原子より高くなる）。組み方は対称性が決めるもので、フィットではない。

- **2 原子分子**: 結合軸に沿った σ / π の結合性・反結合性の梯子を作り、
  縮退した π 準位にアウフバウ + フント則で詰める。
  → O₂ が何も指示しなくてもスピン三重項（↑9 / ↓7）になる。
- **AX_n 型**: 中心原子上に各配位子を向く sp^m 混成を作る。混成の s 重み a² は
  実測結合角 θ から直交条件で決まる。

  ```
  a^2 + b^2 cos(theta) = 0,  a^2 + b^2 = 1   =>   a^2 = -cos(theta)/(1 - cos(theta))
  ```

  H₂O の 104.51° なら a² = 0.2。残りの直交補空間（4 − n 次元）が孤立電子対になる。

自由なパラメータは結合分極 λ ひとつだけで、それも変分最適化する。

## 2. 核子：QMD 差分方程式

### 2.1 ハミルトニアン

各核子を幅 L の固定ガウス波束とし、積状態で期待値をとると古典ハミルトニアンになる。

```
rho_ij = (4 pi L)^{-3/2} exp( -r_ij^2 / (4 L) )                     重なり密度

H = sum_i P_i^2/(2M)
  + (alpha/(2 rho0)) sum_{i!=j} rho_ij                              Skyrme 2 体
  + (beta/((g+1) rho0^g)) sum_i ( sum_{j!=i} rho_ij )^g             Skyrme 密度依存
  + (Cs/(2 rho0)) sum_{i!=j} tau_i tau_j rho_ij                     対称エネルギー
  + (e^2/2) sum_{i!=j, p p} erf(r_ij/(2 sqrt L))/r_ij               クーロン
  + Cz sum_{i<j} exp(-r_ij^2/(2 az^2))                              NN 短距離斥力コア
  + Cp sum_{i<j} d_tau d_spin exp(-r_ij^2/(2 q0^2) - p_ij^2/(2 p0^2))  パウリ
```

- **パウリポテンシャル**が古典核子 MD における反対称性の代役。同種核子を同じ
  位相空間セルから追い出し、フェルミ運動を供給する（Wilets, Dorso–Randrup）。
- **短距離斥力コア**は実際の NN 相互作用の斥力芯（ω 交換 / クォークのパウリ）。
  重心座標のモデルでは、古典粒子が持てないゼロ点斥力の代役も兼ねる。
  これが無いと 4 核子系（(τ,σ) が全部違うのでパウリ対がひとつも無い）が
  1 点に潰れる。
- α, β, γ は探索していない。核物質の飽和条件で決まる標準ソフト Skyrme 値。
  実際、フェルミ運動エネルギーを Thomas–Fermi 汎関数

  ```
  T/A = (3/5) E_F = C_TF rho^{2/3},  C_TF = 0.6 * 20.735 * 6.036 = 75.09 MeV fm^2
  ```

  として陽に入れて E/A(1) = -16 MeV と dE/dx|₁ = 0 を課すと
  α = -124.9 MeV, β = 70.8 MeV が出て、標準値 (-124, 70.5) に一致する。

### 2.2 更新式

H が P に運動項以外で依存する（パウリ項）ので

```
dR/dt = dH/dP != P/M
```

したがって通常の kick–drift–kick leapfrog は使えない。導出される 2 次の更新式は
**陽的中点法（2 次ルンゲ・クッタ）**。

```
R* = R^n + (dt/2) dH/dP(R^n,P^n)
P* = P^n - (dt/2) dH/dR(R^n,P^n)

R^{n+1} = R^n + dt dH/dP(R*,P*)
P^{n+1} = P^n - dt dH/dR(R*,P*)
```

使う解析的な微分（`d rho_ij/dR_i = -rho_ij (R_i - R_j)/(2L)`）:

```
dE_sk2/dR_i = (alpha/rho0) sum_j d rho_ij/dR_i
dE_sk3/dR_i = (beta g/((g+1) rho0^g)) sum_j (rb_i^{g-1} + rb_j^{g-1}) d rho_ij/dR_i
d/dr [erf(r/a)/r] = 2 exp(-r^2/a^2)/(a sqrt(pi) r) - erf(r/a)/r^2
dVp/dR_i = -Vp (R_i - R_j)/q0^2
dVp/dP_i = -Vp (P_i - P_j)/p0^2
```

Δt = 0.20 fm/c で 4000 ステップ後の相対エネルギードリフトは 3.9 × 10⁻⁵（実測）。

### 2.3 基底状態と、見えている運動の正体

基底状態は**同じ H の位相空間最急降下**で作る。R と P の両方を降下させる点が重要で、
パウリ項があるので H の最小点は P ≠ 0（同種核子は運動量空間でも引き離される）。
P → 0 に減衰させると別の状態に行ってしまう。

```
R <- R - muR dH/dR
P <- P - muP dH/dP
```

ここで避けられない事実：**完全に緩和した古典核は静止する**。
最小点では dR/dt = ∂H/∂P = 0 だから当然。
実際の原子核は核子あたり約 20 MeV の量子的ゼロ点フェルミ運動を持つが、
古典モデルはそれを「運動」として表現できない。

したがって画面で見えている核子の運動は

- 明示的に与えた**励起エネルギー E\***（実在の物理量。数 MeV の励起核は実在する）
- 任意の**集団回転 J**（回転バンドとして実在する）

であり、どちらも画面に数値を出している。ここをぼかすと嘘になる。

E\* の与え方も差分方程式で、乱数方向 ξ（正味運動量 0）を 1 組引いて
P = P_gs + λξ とし、H が E_gs + E\* になるよう λ を二分法で決める。
H(λ) は単調増加なので必ず収束する
（毎回新しい乱数キックを足す実装は、キックが必ずエネルギーを上げるだけなので
一度オーバーシュートすると発散する）。

## 3. クォーク：相対論的シンプレクティック差分方程式

### 3.1 ハミルトニアン

```
H = sum_i sqrt(p_i^2 + m_i^2) + V(x)

V = -kappa sum_{i<j} erf(r_ij/r0)/r_ij + sigma * L_Y(x) + V0
kappa = (2/3) alpha_s hbar c        3 クォーク色一重項の色因子
L_Y   = 最小全ストリング長 = 3 点のシュタイナー（フェルマー）木
```

Y 型ストリングは格子 QCD が支持する 3 クォークポテンシャルの形。
`erf(r/r0)/r` は有限のクォークサイズによる正則化。

### 3.2 更新式

H = T(p) + V(x) と分離できるので、**厳密にシンプレクティック**な
kick–drift–kick が使える。

```
p^{n+1/2} = p^n       - (dt/2) grad V(x^n)
x^{n+1}   = x^n       + dt * p^{n+1/2} / sqrt((p^{n+1/2})^2 + m^2)
p^{n+1}   = p^{n+1/2} - (dt/2) grad V(x^{n+1})
```

`dx/dt = p/E` はそのまま相対論的速度 v/c（このモデルでは 0.85c なので相対論は必須）。

### 3.3 ストリングの勾配と閉じ込め

接合点 S は L の最小点にあるので、包絡線定理から dS/dx の項が消えて

```
dL_Y/dx_i = (x_i - S)/|x_i - S|        大きさ 1 の単位ベクトル
```

つまり内向きの力は距離によらず **σ で一定**。どれだけ引き離しても弱くならない
＝クォークは外に出られない。これは仕様として押しつけたものではなく、σ·L という
項の帰結。

**縮退の扱い**：三角形の内角がひとつでも 120° 以上になると、シュタイナー点はその頂点に
退化する。そのとき L = r_vj + r_vk なので、勾配は 2 本の線分の単位ベクトルになる。
この場合を別に導出して実装しないと（退化した頂点の力を 0 にしてしまうと）
エネルギー保存が壊れる。実測で 40 万ステップ後の相対ドリフト 5.8 × 10⁻¹ が
1.0 × 10⁻¹³ に改善した。

### 3.4 核子の大きさはどこから来るか

円軌道の力の釣り合いだけでは大きさは決まらない。

```
(A)  p^2 / sqrt(p^2 + m^2) = (R/3) dV_eq/dR
```

(A) はどの R でも解を持ち、古典的にはエネルギーが下がり続けて R → 0 に潰れる。
核子の大きさは量子的な量なので、**水素原子のボーア半径を決めるのと同じ
ボーア＝ゾンマーフェルト条件**で閉じる。

```
(B)  p R = n hbar          n = 1 が基底のピンホイール
```

(B) を (A) に代入すると R について 1 本の方程式になり、二分法で解く。
結果（n = 1）: R = 0.3677 fm, p = 536.7 MeV/c, v = 0.848c。
R も p も手で入れていない。

V₀ は構成子クォーク模型の標準的な加算定数。n = 1 のときに核子質量
938.918 MeV に合わせて**一度だけ**決め（V₀ = -1581.5 MeV）、以後触らない。
したがって n = 2, 3, … の軌道は本当に重くなる（実在の N\* 共鳴と同じ振る舞い）。

### 3.5 正直に言っておく限界

- このピンホイールは軌道角運動量 3nħ を持つ。実際の核子基底状態は L = 0 の J = 1/2。
  古典軌道は s 波になれない。これは**同じハミルトニアンの、同じ大きさ・同じ
  運動量スケールでの古典状態**である。
- 陽子と中性子の質量差 1.3 MeV は電磁効果と m_d − m_u によるもので、このモデルは
  分解しない（アイソスピン対称、m_u = m_d = 336 MeV で扱っている）。

## 4. スケールについて

| 階層 | 実寸 |
|---|---|
| 原子 | ≈ 10⁻¹⁰ m |
| 原子核 | ≈ 10⁻¹⁵ m |
| 核子内クォーク間距離 | ≈ 10⁻¹⁵ m |

実寸で並べると原子核は原子パネルの 1 ピクセルの 10 万分の 1 になって見えないので、
パネルごとに倍率を変えている。**誇張しているのは倍率だけ**で、

- 各パネルに実スケールバー（pm / fm）
- 原子パネルに対する倍率
- 「1 px = 何 pm」

を常に表示している。3 階層は物理としても独立（エネルギースケールが
10 eV / 10 MeV / 1 GeV で 8 桁離れている）で、結合しているのは
**電子側に渡る核の電荷 Z と質量数 A** だけ。これが実際の物理的な結合でもある。

## 5. 再現手順

```bash
# ネイティブ自己テスト（clang 系が必要。olive.c の C99 指定イニシャライザが g++ で通らない）
clang++ -O2 -std=c++17 -I. src/atom_os.cpp -o atom_os

./atom_os e        # 電子 VMC エネルギー vs 厳密値
./atom_os n        # 核の基底状態 vs 実験値
./atom_os dyn      # 核の時間発展のエネルギー保存（Δt 依存性）
./atom_os q        # クォーク（質量・保存・閉じ込め）
./atom_os diag 1.5 # サンプラーの検証（<1/r> = zeta が出るか）
./atom_os cal      # 核のパラメータ校正（座標降下、数分）
./atom_os opt      # 変分パラメータ表の再生成（数分）
./atom_os png 7 900 5 1   # 1 フレーム PNG 出力（系, ステップ, 軌道, 表示)

# WASM
EMSDK=/path/to/emsdk ./build.sh atom_os
```
