🌊 River （Painlevé–Gullstrand） (C++ / WASM)

同じブラックホールの、もう一つの書き方。ここでは空間が厳密にユークリッドで、 共形因子すらありません。ラプスも厳密に 1 なので、水に対する光の速さは厳密に c。動いているのは格子そのものです：
ds² = −dt² + (dr + v(r)dt)² + r²dΩ²、　v(r) = √(2m/r) —— これはニュートンの脇出速度そのもの。
地平面 r = 2m は「光が止まる面」ではなく、川の流れが光速に達する面。内側では川が超光速で、 外向きの光は水に対して c で進んでいるのに下流へ運ばれます。負になる量は一つも出てきません。

検算済み：v(2m) = 1.000000000000、外向き dr/dt は r=2m で 0.000e+00、r=1m で −0.414214（全速で泳いでも下流へ）。 地平面から特異点までの固有時は 4m/3 = 1.333333332 m（無限遠から落ちた場合）、最長で πm = 3.141592654 m。 太陽質量で 6.567 μs、M87* で 711.5 分。
同じ時空を静止格子＋可変光速で書いたのが flatgrid_os で、影の半径 √27 m で 10桁一致します。
